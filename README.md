## Engineering principles

- Start with the clinical or operational problem.
- Make provenance, assumptions, and limitations visible.
- Test data contracts and failure paths—not only happy paths.
- Treat AI outputs as evidence to evaluate, not authority to trust blindly.
- Build technology that supports healthcare professionals rather than replacing their judgment.
